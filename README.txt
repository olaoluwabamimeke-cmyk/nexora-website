NEXORA — Phase 1 Front-End Preview

Files:
- index.html: website structure
- styles.css: responsive visual design
- app.js: demo directory, search/filter, modal form validation, mobile navigation

How to preview:
1. Open index.html in a browser, or upload the whole folder to a static host.
2. For a public preview, upload the ZIP to Netlify Drop or create a new Netlify site from the extracted folder.
3. This is a front-end prototype only. Business submissions are validated in the browser but NOT stored or sent.
4. Listings are clearly marked sample data and do not represent verified real businesses.
5. Supabase authentication, database, file uploads, administrator approval, real business profiles, and email delivery are not configured.

Before production:
- Configure Supabase project and environment-safe public configuration.
- Apply database migrations and Row Level Security policies.
- Implement backend authorization and admin review.
- Replace demonstration listings with approved real listings.
- Review privacy and terms for actual data practices.
